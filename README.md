# Causal Representation Learning from Multimodal Clinical Records under Non-Random Modality Missingness

This repository contains the implementation of our causal representation learning framework for handling multimodal clinical data with Missing-Not-At-Random (MMNAR) patterns. The pipeline integrates structured EHR features, MIMIC-CXR image embeddings, and MIMIC-IV clinical notes, then applies a rectifier to reduce residual modality-specific bias.

All code in this repository is developed and tested with publicly available PhysioNet datasets:

* MIMIC-IV v3.1
* MIMIC-IV-Note: Deidentified free-text clinical notes v2.2
* Generalized Image Embeddings for the MIMIC Chest X-Ray dataset v1.0

Access to these datasets requires the appropriate PhysioNet credentialing and data-use agreements.

## Overview

The framework consists of three key components:

1. **MMNAR-Aware Modality Fusion**: integrates representations from structured EHR data, chest X-ray embeddings, discharge notes, and radiology reports.
2. **Representation Balancing Module**: encourages generalization across different modality missingness patterns.
3. **Multitask Outcome Prediction and Rectifier Module**: jointly predicts clinical outcomes and applies a rectifier to correct residual bias.

## Data Setup

Before running the pipeline, prepare the local data directories below.

### Structured MIMIC-IV Tables

`data_preprocessing.py` downloads the required MIMIC-IV v3.1 structured tables from the public BigQuery dataset `physionet-data`. Configure Google Cloud application-default credentials with access to PhysioNet BigQuery before running the script.

If your default credentials do not already specify a billing project, pass one explicitly:

```bash
python data_preprocessing.py --gcp-project YOUR_GCP_PROJECT_ID
```

### MIMIC-CXR Image Embeddings

Download **Generalized Image Embeddings for the MIMIC Chest X-Ray dataset v1.0** from:

https://physionet.org/content/image-embeddings-mimic-cxr/1.0/

After extraction, move or copy the `p*` folders from the downloaded `files/` directory into the local `mimiciv_cxr/` directory. The expected layout is:

```text
mimiciv_cxr/
  p10/
    p10000032/
      s.../
        *.tfrecord
  ...
  p19/
```

The CXR preprocessing code expects paths of the form `mimiciv_cxr/pXX/p<subject_id>/<study>/*.tfrecord`.

### MIMIC-IV-Note

Download **MIMIC-IV-Note v2.2** from:

https://physionet.org/content/mimic-iv-note/2.2/

Extract all CSV files and place them directly in the local `mimiciv_note/` directory. At minimum, the pipeline uses:

```text
mimiciv_note/
  discharge.csv
  radiology.csv
  discharge_detail.csv
  radiology_detail.csv
```

## Usage

### Step 0: Data Preprocessing

Run the preprocessing script to generate harmonized structured features, patient-level note embeddings, and aggregated CXR embeddings:

```bash
python data_preprocessing.py --gcp-project YOUR_GCP_PROJECT_ID
```

If your Google Cloud application-default credentials already define the project, `--gcp-project` can be omitted.

This script will:

* Select a reproducible MIMIC-IV cohort from BigQuery.
* Download required structured hospital and ICU tables to `mimiciv_data/`.
* Build leakage-aware index-admission features and multitask labels.
* Generate patient-level embeddings from `mimiciv_note/discharge.csv` and `mimiciv_note/radiology.csv`.
* Aggregate downloaded MIMIC-CXR TFRecord embeddings from `mimiciv_cxr/`.

### Step 1: Train the Multimodal Model

Run:

```bash
python multimodal_missingness.py
```

This script will:

* Load `mimiciv_data/patient_features_noleak.csv`.
* Load `mimiciv_data/cxr_embeddings_aggregated.csv`.
* Load `mimiciv_data/patient_text_embeddings_nan.csv`.
* Train the multimodal model with MMNAR-aware fusion and representation balancing.
* Save model artifacts in `outputs_model/models/`.
* Save prediction and metric files in `outputs_model/results/`, including `enhanced_complete_predictions.csv`.

### Step 2: Apply the Rectifier

After obtaining the prediction CSV file, run:

```bash
python apply_rectifier.py \
  --csv_path outputs_model/results/enhanced_complete_predictions.csv \
  --selective \
  --output_prefix outputs_model/results/enhanced_results
```

Parameters:

* `--csv_path`: path to the predictions CSV file from Step 1.
* `--selective`: apply only corrections that pass the selective correction criteria.
* `--output_prefix`: prefix for corrected prediction and plot outputs.

This script will:

* Load saved predictions.
* Apply the rectifier correction to adjust modality-pattern-specific bias.
* Save corrected predictions to `<output_prefix>_selective_results.csv`.
* Save ROC and PR comparison plots to `<output_prefix>_roc.png` and `<output_prefix>_pr.png`.
